# @dolgikh-maks/browserslist-config

Shared Browserslist configuration for front-end projects.

## Installation

```sh
npm install --save-dev @dolgikh-maks/browserslist-config caniuse-lite
```

## Usage

Add the following to your `package.json` or `.browserslistrc`:

**package.json**
```json
{
  "browserslist": [
    "extends @dolgikh-maks/browserslist-config"
  ]
}
```

**.browserslistrc**
```
extends @dolgikh-maks/browserslist-config
```
